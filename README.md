# TokenPet for Windows

바탕화면에서 AI 사용 한도를 알려주는 **우사기 펫**. 이번 버전은 사용자가 첨부한 그림 4장과 [참고 릴](https://www.instagram.com/reel/DW6I9jyk8Co/)을 바탕으로 대기·산책·야하·우라·엎드리기·눈 뜨고 쉬기 이미지를 모두 다시 만들었습니다. 작은 눈, 짧은 팔다리와 둥근 얼굴을 살리고, 납작하게 엎드린 동작을 추가했습니다.

현재 실제 연동은 **ChatGPT로 로그인한 Codex CLI**를 지원합니다. Claude, Gemini 및 일반 ChatGPT 대화의 사용량은 아직 지원하지 않습니다. 구독 한도는 정확한 잔여 토큰 수가 아닌 서버가 제공하는 **남은 비율**로 표시합니다. API 키 전용 계정의 토큰 잔액을 계산하지 않습니다.

## 실행

1. Windows 10/11에서 .NET 9 Desktop Runtime과 Codex CLI를 준비합니다.
2. 터미널에서 `codex login`으로 ChatGPT 계정에 로그인합니다.
3. 압축을 푼 폴더의 `TokenPet.exe`를 실행합니다. 소스 프로젝트에서 빌드한 경우에는 `release/TokenPet.exe`입니다. npm 기본 설치 경로와 PATH의 실행 파일을 자동 탐색합니다.
4. 자동 탐색이 실패하면 **연동 설정 → codex.exe 선택**으로 직접 지정합니다. `.cmd` 또는 `.ps1` 대신 실제 네이티브 실행 파일이 필요합니다.

## 화면 표시

기본 화면은 **펫 + 머리 위 요약**입니다. 창 테두리나 사용량 카드 없이 우사기와 작은 말풍선만 표시합니다. 말풍선에는 `5시간 77% · 주간 43%`처럼 남은 사용 한도를 요약하며, 산책·점프할 때 머리 위를 따라갑니다. Codex에서 잔여 토큰 개수를 제공하지 않으므로 수치는 **남은 한도(%)**입니다.

펫을 **우클릭 → 표시 모드**에서 다음 중 선택합니다.

- **펫 + 머리 위 요약**: 우사기와 요약 말풍선.
- **펫만 표시**: 말풍선과 부가 문구까지 모두 숨기고 우사기만 표시.
- **상세 카드 + 펫**: 모든 한도와 초기화 시각, 새로고침·연동 버튼을 표시.

표시 모드는 저장되어 다음 실행에도 유지됩니다. 요약이 길면 줄임표로 표시하며, 말풍선에 마우스를 올리거나 상세 카드에서 조회 상태를 확인합니다. 연결이 실패하면 이전 숫자 대신 **연결 실패/연동 필요**를 표시합니다. 샘플은 말풍선에도 **샘플 데이터**라고 표시합니다.

명령행에서 `TokenPet.exe --summary`, `--pet-only`, `--details`로 원하는 화면을 바로 열 수 있습니다. 연동 설정·새로고침·종료는 어느 화면에서든 우클릭 메뉴에서 사용할 수 있습니다.

펫과 카드의 빈 공간을 드래그하면 이동합니다. 우클릭 메뉴에서 샘플 보기, 항상 위에 표시, 종료를 선택할 수 있습니다. 최소화하면 작업 표시줄에서 다시 열 수 있습니다. 한도는 5분마다 갱신되며 새로고침 버튼으로 바로 조회할 수 있습니다. 25% 이하에서는 주의 문구, 10% 이하에서는 자동 모드의 토끼가 휴식합니다.

## 토끼 움직임

- **대기**: 첫 번째 참고 그림처럼 작은 팔을 내려놓은 기본 자세로 가볍게 호흡.
- **산책**: 펫 공간 안에서 좌우로 이동하며 방향 전환과 발걸음 바운스.
- **우라!**: 짧은 팔과 작은 입을 유지한 채 폴짝 점프, 착지 시 몸이 살짝 눌리는 동작.
- **야하!**: 작은 손을 볼 가까이에 올리고 몸을 까딱이며 인사. 펫을 더블클릭해도 인사합니다.
- **엎드리기**: 세 번째 참고처럼 몸을 넓고 납작하게 엎드리고 천천히 호흡. 머리 위 요약도 낮아진 머리 위치를 따라갑니다.
- **눈 뜨고 쉬기**: 네 번째 참고의 멍한 눈 뜬 표정으로 기울어 쉬기.
- **드래그 반응**: 창을 끄는 동안 매달린 듯한 포즈, 놓으면 인사 후 원래 모드로 복귀.

우클릭 → **우사기 움직임**에서 자동 모드 또는 원하는 동작을 선택합니다. 자동 모드는 4~8초 간격으로 동작을 바꾸고, 한도가 10% 이하이면 엎드리기와 눈 뜨고 쉬기를 사용합니다. 최소화 시 애니메이션 타이머를 멈춥니다. 그림은 포즈 6장의 PNG이며 호흡·회전·이동·점프는 코드로 보간합니다.

`usagi-compact.gif`는 머리 위 요약 모드 미리보기, `rabbit-motions.gif`는 동작 모음, `rabbit-poses.png`는 포즈 모음입니다. 현재 사용하는 이미지는 `Assets/usagi-v2-{idle,walk,wave,jump,prone,sleep}.png`입니다. 첨부한 원본 4장은 `Assets/References-20261018/`에 보존했습니다. 이전 이미지도 프로젝트의 `Assets`에 보존했습니다.

`TokenPet.exe --demo`는 **샘플 데이터**라고 표시되는 미리보기입니다. 실제 연결 실패 시 이전 수치를 현재 잔여량처럼 표시하지 않습니다. 초기화 시간이 지났더라도 서버 확인 전까지 잔여량을 임의로 늘리지 않습니다.

## 빌드 및 검증

.NET 9 SDK에서 프로젝트 폴더를 열어 실행합니다. 외부 NuGet 패키지는 사용하지 않습니다.

```powershell
dotnet build -c Release
dotnet run -c Release -- --self-test
dotnet run -c Release -- --screenshot
dotnet run -c Release -- --screenshot --pet-only
dotnet run -c Release -- --screenshot --details
dotnet run -c Release -- --motion-preview
dotnet run -c Release -- --probe
dotnet publish -c Release --no-self-contained -o release
```

`--self-test`는 한도 응답·요약 처리, 드래그를 포함한 7개 동작의 이동 범위, 이미지 투명도, 동작 복귀, 낮은 한도에서의 휴식, 세 가지 표시 모드, 머리 위 요약의 위치 추적 및 창 밖 잘림, 연결 실패 시 이전 숫자 제거를 검사합니다. `--screenshot`은 요약 화면을 `preview.png`로, `--pet-only`/`--details` 옵션을 더하면 각각 `preview-pet-only.png`/`preview-details.png`로 저장합니다. 화면 검증은 저장된 개인 설정을 읽거나 수정하지 않습니다. `--motion-preview`는 동작 모음 GIF와 포즈 모음, 144프레임의 `usagi-compact.gif`를 저장합니다. `--probe`는 실제 로그인으로 조회한 한도만 `probe.json`에 저장합니다. 검사 실패 시 종료 코드 1과 `check-error.txt`를 남깁니다.

배포 시 `release` 폴더 전체가 필요하며, 이 빌드는 .NET 9 Desktop Runtime이 설치된 PC에서 실행됩니다.

## 데이터 처리

문서화된 `codex app-server`의 `initialize` → `initialized` → `account/rateLimits/read`만 호출합니다. 대화나 작업을 생성하지 않습니다. Codex 자체 인증을 사용하며 앱에서 API 키나 인증 파일을 읽거나 저장하지 않습니다. Codex는 사용량 확인을 위해 서비스에 연결합니다.

선택한 Codex 실행 경로, 창 위치, 표시 모드를 `%LOCALAPPDATA%/TokenPet/settings.json`에 저장합니다. 로그아웃은 Codex CLI에서 관리합니다. 다른 AI는 각 서비스의 공식 한도 조회 방식을 확인한 뒤 별도 연동이 필요합니다.

공식 프로토콜: [Codex App Server](https://learn.chatgpt.com/docs/app-server)
